# Google Sheets の設計

## 組み込みレイアウト

新しい月になると、アプリは `YYYY-MM` タブを作ります。先頭 2 行がヘッダーで、その後に暦日ごとの行が続きます。

| 列 | 内容 |
| --- | --- |
| A | ISO 形式の日付 |
| B | 曜日 |
| C | その日の最初の Bluetooth 検出。出社として扱う |
| D | その日の最後の Bluetooth 検出。退社として扱う |
| E | 手入力する在宅勤務時間 |
| F | 手入力する休憩時間 |
| G | 計算された勤務時間 |
| H | 8 時間を超えた勤務時間 |

スプレッドシートのロケールに依存しないよう、ISO 日付と英語の数式名を使います。時刻は秒まで記録します。

## 既存テンプレート

`template_sheet_id` は、テンプレートタブと出退勤データが同じスプレッドシートにある場合だけ指定してください。月次タブがない場合、アプリがテンプレートを複製して `A3` に月初日を設定します。テンプレートでは A 列を日付、C 列を出社、D 列を退社として維持する必要があります。

## 履歴ブックを共有テンプレートにしない理由

旧バージョンからリンクされていたブックを読み取り専用で確認しました。200 を超える月次タブを持つ長期利用の個人用ブックで、`YYYY-MM` タブにも壊れた数式参照と不整合があります。ブック全体のコピーは無関係な履歴を含み、タブだけの公開でも数式の問題が残ります。

そのため、OSS の既定動作はアプリが生成する再現可能なレイアウトです。将来デザイン付きの公開テンプレートを用意する場合は、データを含まない別ブックを作り、上記の列仕様に対してテストしてください。履歴ブックを公開しないでください。
