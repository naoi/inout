# Contributing

Thank you for improving In-Out Tracker.

1. Create a focused branch and keep secrets, real Bluetooth addresses, and spreadsheet IDs out of commits.
2. Install development dependencies with `python -m pip install -e '.[dev]'`.
3. Run `pytest` and `ruff check .` before opening a pull request.
4. Explain Raspberry Pi model, Raspberry Pi OS version, phone type, and the relevant log output in bug reports.

Please do not include attendance records or Google service account files in issues.
